## Files

- **RawBinary.md**  
  The master source file containing all 24 raw binary codices.  
  Structured as Markdown headers (`## Site Name`) followed immediately by the pure binary string (0s and 1s).  
  As codices are fully transmitted and completed, they become active lenses automatically.

- **base.py**  
  The main interactive explorer and integration engine.  
  Features:
  - Dynamic loading of **all complete codices** from `RawBinary.md`
  - Pulse/breath extraction
  - Zeckendorf representation for non-consecutive branching (zero interference)
  - Phi-routed golden-angle spiral growth in the Poincaré hyperbolic disk
  - Hierarchical multi-lens cycling across depths
  - Interactive controls:
    - **Depth slider** (6–24)
    - **Mouse drag** to pan
    - **Scroll wheel** to zoom
    - Dynamic node sizing and alpha based on hyperbolic distance (glowing depth effect)
  - Dark theme with cyan glow on black background

- **angkor_wat_central_temple_complex.py**, **bell_rock_sedona.py**, etc.  
  Individual prototype scripts for specific sites (legacy/early versions).  
  These may be kept for reference or single-lens testing, but the full multiverse experience now lives in `base.py`.
