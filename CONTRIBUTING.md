# Contributing to Radial Hyperbolic Architecture Prototype

Thank you for your interest in this project! This is a living exploration of consciousness, geometry, physics, and the nature of reality — built one resonant layer at a time.

All contributions are welcome — big or small, code or ideas.

## How to Contribute

### 1. New Experiments / Modes
- The best way to contribute is by adding new experiments!
- Create a new file in the `/experiments/` folder.
- Name it clearly: `human_body_your_idea.py`
- Use existing experiments as templates (they all import from `core/` and `visualization/`).
- Your new mode will automatically work with the shared hyperbolic lattice and golden-ratio foundation.

Examples of great contributions:
- New sensory modes
- Physics simulations (gravity, electromagnetism, quantum effects)
- Biological systems (immune, endocrine, DNA)
- Consciousness states (lucid dreaming, flow states, non-dual awareness)
- Multi-human interactions
- Visual/audio enhancements

### 2. Improving Core Systems
- Changes to `/core/` (geometry, math, seeding) or `/visualization/` should be conservative.
- These are shared by all experiments — stability matters.
- If you improve something here, test multiple experiments to make sure nothing breaks.

### 3. Ideas, Feedback, Bug Reports
- Open an Issue!
- Share what the simulation makes you feel, think, or realize.
- Suggest new domains for the Grand Map.
- Report bugs or strange behavior.

### 4. Pull Requests
- Fork the repo
- Create a branch with a clear name
- Make your changes
- Open a PR with a short description of what you added and why

Every merged contribution becomes part of the living map of reality we're building together.
